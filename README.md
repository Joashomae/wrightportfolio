# Deana Wright — Portfolio

A responsive static portfolio based on the supplied resume. No dependencies, account credentials, build step, or external fonts are needed.

## Preview
Open index.html in a browser. Or run `python3 -m http.server 8000` inside this folder and visit http://localhost:8000.

## Deploy to Vercel using GitHub
1. Extract this ZIP.
2. Sign in to GitHub and create a repository named deana-portfolio.
3. Use Add file → Upload files. Upload index.html, style.css, favicon.svg, vercel.json, and this README directly at the repository root. Commit the files.
4. Sign in to Vercel with GitHub. Choose Add New → Project and import deana-portfolio. Grant access to that repository if asked.
5. Set Framework Preset to Other. Keep Root Directory at the repository root. Leave Build Command empty. Use the repository root (.) for Output Directory if an override is required. No install command is needed.
6. Deploy. Open the deployment URL and check the page on mobile and desktop, navigation links, and email link.
7. Later changes committed to the connected production branch will trigger a new deployment.

Dashboard wording may vary. Do not share passwords or access tokens in chat.

## Content notes
The public page excludes street address and date of birth. It includes the resume email address. The original PDF is intentionally not included because it contains personal information. Employment history, qualifications, project outcomes, testimonials, and professional licenses have not been invented. Add verified project examples when available.

Edit text in index.html and colors/layout in style.css. The contact link opens the visitor's email application; there is no server-side contact form.
